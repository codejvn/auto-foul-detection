# Soccer AI Referee — Full Automation Research Project

## Agent workflow
This project uses the `/subagent-driven-development` skill for all implementation work.
- **Architect:** Fable 5 (current model) — planning, decomposition, review
- **Subagents:** Sonnet (`claude-sonnet-4-6`) — all code writing and execution tasks

When given any implementation task, invoke `/subagent-driven-development` with Sonnet as the subagent model.

## What this project is arguing
That an automated system can match or exceed human VAR accuracy, and can
quantify its own uncertainty in a way human refs cannot. The output of this
project is both a working pipeline AND a calibration argument: our confidence
scores should predict when humans disagree.

## Current pipeline (generated by codegen.py)
```
frame_extractor.py      → OpenCV, 16 evenly-spaced frames
contact_detector.py     → CLIP zero-shot, player contact detection
foul_classifier.py      → VideoMAE (Kinetics), foul type classification
severity_assessor.py    → Farneback optical flow heuristic
location_detector.py    → CLIP zero-shot, penalty box detection
ruling_engine.py        → pure Python IFAB rules, deterministic
pipeline.py             → orchestrates all modules, CLI entry point
```

## What we are adding (do not touch existing files unless instructed)
```
shot_boundary_filter.py → PySceneDetect, removes camera cuts before analysis
judgment_layer.py       → Fable 5 API call for ambiguous cases only
                          (cases where any module confidence < 0.65)
ruling_engine.py        → MODIFY: add confidence routing and human_review flag
pipeline.py             → MODIFY: insert shot_boundary_filter after extract_frames,
                          insert judgment_layer before ruling_engine
validator.py            → VARS dataset accuracy + calibration script
```

## Public API contracts (do not break these)
```python
extract_frames(video_path, num_frames=16) -> tuple[list[np.ndarray], list[float]]
detect_contact(frames) -> {"contact": bool, "confidence": float}
classify_foul(frames) -> {"foul_type": str, "confidence": float}
assess_severity(frames, foul_type) -> {"severity": str, "confidence": float, "peak_motion": float}
detect_location(frames) -> {"in_penalty_box": bool, "confidence": float}
make_ruling(contact, foul, severity, location, judgment=None) -> ruling dict
```

```json

  "punishment": "free kick + yellow card",

  "human_review_recommended": false,
  "judgment_layer_used": false,
  "judgment_layer_reasoning": null,
  "low_confidence_modules": []
}
```

## Confidence routing logic
- Any module confidence < 0.65 → flag that module in low_confidence_modules
- If ANY module confidence < 0.65 → call judgment_layer (Fable 5)
- If ALL module confidences >= 0.65 → skip judgment_layer, use ruling_engine directly
- human_review_recommended = overall confidence < 0.60

## Judgment layer (Fable 5) contract
Input: structured dict with all module outputs + their confidences + foul type context
Output: {"foul_type": str, "severity": str, "reasoning": str, "confidence": float}
The judgment layer can OVERRIDE foul_classifier and severity_assessor outputs.
It cannot override contact_detector or location_detector (those are factual, not judgment calls).

## VARS dataset (for validator.py)
- Download from: https://github.com/SoccerNet/sn-mvfoul
- Contains ~3901 clips with human VAR decisions
- Ground truth fields: action_class, severity_class, offence
- Key metric: does our confidence score predict human disagreement?
  (clips labeled differently by different annotators = our hardest cases)

## Models in use
- openai/clip-vit-base-patch32 (contact_detector, location_detector)
- MCG-NJU/videomae-base-finetuned-kinetics (foul_classifier)
- Farneback optical flow via OpenCV (severity_assessor)
- claude-fable-5 via API (judgment_layer — ambiguous cases only)

## GPU memory
~4.5 GB baseline. Shot boundary filter adds ~0.2 GB peak. Judgment layer is API-only.

## Key research claims this project makes
1. Perception accuracy: foul_classifier achieves X% on VARS dataset
2. Ruling accuracy: full pipeline matches human VAR decisions at Y%
3. Calibration: confidence < 0.65 cases correspond to clips where human annotators
   disagreed — this is the novel claim, proved in validator.py
